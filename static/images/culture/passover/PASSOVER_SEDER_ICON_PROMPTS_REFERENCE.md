# Passover Seder Icon Prompts Reference

> Recovered/confirmed prompt system used for the Passover Seder step icon series
> This captures the original icon-language reference so it can be reused without depending on chat history

## Core Passover Style Block

```text
Create a circular icon (perfect circle, no border). Style: Abstract Corporate Memphis vector illustration. Minimalist flat design. Paper cut-out aesthetic with layered construction paper texture. Hard-edged geometric shapes assembled like a collage. No edge outlines, minimal internal lines, no sketchiness. Matte paper finish. For metallic objects use metallic foil paper texture. For glass use semi-transparent vellum texture. Drop shadows between paper layers to show depth. Muted earthy color palette with mid saturation, flat fills, no gradients. Output as PNG, 512x512px, transparent background outside the circle.
```

## Practical Design Lineage

This prompt set establishes the foundational CFM culture-icon language:
- circular devotional-symbol icon
- paper cut-out layered collage
- muted earthy sacred palette
- hard-edged simplified object forms
- symbolic and instructional rather than realistic

## Reuse Guidance

For current and future generators:
- preserve the design characteristics
- do not rely on wording like `match this exact style` or `copy these icons`
- describe the visual traits directly
- treat this as the original reference vocabulary for the Passover/Holy Week/festival icon system
